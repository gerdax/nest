# Nest

Current card interaction engine and motion playground.

[Open the live playground](https://gerdax.github.io/Nest/) · [Launch and engine API](prototype/README.md)

Run locally from the repository root:

```sh
python3 prototype/serve.py
```

Open http://127.0.0.1:8937/prototype/. The current source is on `main`; GitHub Pages serves the static build from `gh-pages`. Earlier prototypes remain in Git history.
